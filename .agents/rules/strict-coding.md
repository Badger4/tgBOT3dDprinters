# Strict Coding Guidelines

**Activation**: Always On

1. **No Unprompted Changes**: NEVER modify existing, working code unless explicitly requested. Do not add boilerplate, extra features, or unrequested dependencies.
2. **Structural Integrity**: New code must seamlessly integrate with the existing architecture. Keep it optimized, modular, and DRY.
3. **No Hallucinations**: Do not guess requirements. If a task is ambiguous, stop and ask clarifying questions.
4. **Verification Loop**: Before making file changes, explain what you will do. Always run tests to verify that existing functionality is not broken.
