# Керівництво для контриб'юторів / Contributing Guidelines

Дякуємо за ваш інтерес до покращення проєкту **3D Printer Farm Telegram Bot**! Ми вітаємо будь-які внески: виправлення багів, додавання нових функцій, покращення документації чи оптимізацію WebApp.

---

## 🚀 Як швидко розпочати розробку

### 1. Клонування репозиторію та налаштування оточення

```bash
# Клонуйте репозиторій
git clone https://github.com/Badger4/tgBOT3dDprinters.git
cd tgBOT3dDprinters

# Створіть та активуйте віртуальне середовище Python 3.10+
python -m venv .venv

# На Linux / macOS:
source .venv/bin/activate

# На Windows:
.venv\Scripts\activate

# Встановіть залежності проєкту
pip install -r requirements.txt
```

### 2. Налаштування змінних середовища `.env`

Скопіюйте шаблон `.env.example` у файл `.env` та вкажіть ваш токен бота і Chat ID адміністратора:

```bash
cp .env.example .env
```

Редагуйте `.env`:
```env
TELEGRAM_BOT_TOKEN=ваший_токен_бота
ADMIN_CHAT_ID=ваший_чат_ід
STORAGE_DIR=./printers_storage
```

## 🧪 Запуск автотестів

Перед створенням Pull Request переконайтеся, що всі юніт-тести проходяться без помилок:

```bash
# Запуск автотестів через pytest
pytest tests/
```

## 📐 Правила та стандарти розробки

1. **Гігієна безпеки**:
   - **НІКОЛИ** не додавайте хардкод токенів, секретів, API-ключів чи паролів у код або коміти.
   - Усі секрети мають зчитуватися з `.env` через [config.py](config.py).
   - Усі файли користувачів та бінарні сховища мають зберігатися в `printers_storage/` (який знаходиться у `.gitignore`).

2. **Найменування гілок**:
   - `feature/назва-фічі` — для нових функцій.
   - `fix/назва-багу` — для виправлень помилок.
   - `docs/опис-змін` — для оновлення документації.

3. **Оформлення комітів**:
   - Пишіть зрозумілі повідомлення комітів з префіксами (`feat:`, `fix:`, `docs:`, `test:`, `refactor:`).
   - Приклад: `feat: Add support for multi-tray Bambu AMS v2`.

4. **Pull Requests**:
   - Перевірте, що проєкт збирається та `pytest tests/` повертає `100% passed`.
   - Опишіть внесені зміни та мету вашго PR.
