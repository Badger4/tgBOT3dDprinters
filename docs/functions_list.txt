================================================================================
          3D PRINTER FARM TELEGRAM BOT - ПОВНИЙ СПИСОК ТА ОПИС ФУНКЦІЙ
================================================================================

1. ФАЙЛ: printer.py
--------------------------------------------------------------------------------
- main()
  Опис: Головна точка входу в програму. Створює екземпляр PrinterBotApp, ініціалізує 
        його та запускає асинхронний цикл бота через asyncio.run(). Обробляє 
        граціозну зупинку по KeyboardInterrupt.


2. ФАЙЛ: config.py
--------------------------------------------------------------------------------
(Модуль конфігурації. Не містить окремих функцій, але ініціалізує змінні 
оточення TELEGRAM_BOT_TOKEN, ADMIN_CHAT_ID, STORAGE_DIR, налаштовує UTF-8 
для кодування вхідних/вихідних потоків та логування у файл printer_bot.log).


3. ФАЙЛ: orca_hook.py
--------------------------------------------------------------------------------
- main()
  Опис: Автоматичний скрипт пост-обробки (Hook) для слайсера Orca Slicer. Приймає 
        шлях до згенерованого G-code через аргументи командного рядка, шукає 
        вагу філаменту (filament used [g]) та кешує її у файл last_sliced_weight.json.


4. ФАЙЛ: bot/keyboards.py
--------------------------------------------------------------------------------
- get_main_keyboard(is_admin: bool) -> ReplyKeyboardMarkup
  Опис: Створює головну клавіатуру бота з основними розділами (Принтери, Стан 
        ферми, Історія друку, Сповіщення) та додає кнопку "Адмінка", якщо is_admin=True.

- get_printers_keyboard(printers: Dict[str, BambuPrinter]) -> ReplyKeyboardMarkup
  Опис: Створює клавіатуру зі списком усіх доданих 3D-принтерів, а також кнопками 
        "Додати принтер" та "Головне меню".

- get_printer_menu_keyboard(printer: BambuPrinter) -> ReplyKeyboardMarkup
  Опис: Формує меню управління для конкретного принтера (Статус, Камера, ШІ 
        Аналіз, GIF Анімація, Швидкість, Підсвітка, Слоти AMS, Філамент, 
        Пауза/Відновити, Сповіщення, Видалити принтер, Назад).

- get_admin_keyboard() -> ReplyKeyboardMarkup
  Опис: Формує меню панелі адміністратора (Користувачі, Нові користувачі, 
        Головне меню).

- get_filament_menu_keyboard() -> ReplyKeyboardMarkup
  Опис: Створює меню дій з філаментом (Обрати котушку зі складу, Нова котушка, 
        Ручне введення ваги, Ціна 1 кг).

- get_spools_keyboard(spools: Dict[str, Dict[str, Any]]) -> ReplyKeyboardMarkup
  Опис: Формує клавіатуру вибору з каталогу котушок пластику на складі.


5. ФАЙЛ: bot/states.py
--------------------------------------------------------------------------------
(Модуль опису FSM-станів aiogram для діалогів бота):
- AddPrinterStates(StatesGroup): Стани додавання принтера (name, ip, access_code, serial_number).
- PrinterMenuStates(StatesGroup): Стани управління принтером (confirm_stop_print, edit_filament_weight, confirm_delete_printer).
- AdminStates(StatesGroup): Стан адміністрування користувача (manage_user).


6. ФАЙЛ: models/printer.py (Клас BambuPrinter)
--------------------------------------------------------------------------------
- __init__(config: Dict[str, Any], storage: StorageManager, save_callback: Optional[Any] = None)
  Опис: Конструктор класу принтера. Ініціалізує параметри підключення (IP, access_code, 
        serial_number), налаштування електроенергії, вартості пластику та живі 
        показники телеметрії.

- init_mqtt()
  Опис: Підключається до MQTT-брокера принтера Bambu Lab по порту 8883 (SSL/TLS). 
        Налаштовує обробники подій та надсилає запит pushall.

- destroy()
  Опис: Зупиняє фоновий цикл MQTT та коректно закриває мережеве з'єднання.

- _on_connect(client, userdata, flags, rc)
  Опис: Внутрішній коллбек успішного MQTT-підключення. Підписується на топік 
        device/{serial_number}/report та запитує повний статус принтера.

- _on_error(client, userdata, rc)
  Опис: Внутрішній коллбек обробки помилок MQTT-з'єднання.

- _trigger_save()
  Опис: Потокобезпечно викликає асинхронну функцію збереження конфігурації у 
        головному циклами подій asyncio.

- _try_ftps_fetch()
  Опис: Фоново запускає потік для скачування друкованого файла через FTPS з SD-карти 
        принтера для точного визначення ваги моделі.

- _on_message(client, userdata, msg)
  Опис: Обробник телеметрії MQTT. Зчитує temperatures сопла/столу, % прогресу, 
        хвилини, шари, статус gcode_state, стан підсвітки, помилки HMS, стан AMS 
        та автоматично списує вагу пластику після старту/завершення.

- pause() -> bool
  Опис: Надсилає команду MQTT "pause" для призупинення поточного друку.

- resume() -> bool
  Опис: Надсилає команду MQTT "resume" для продовження друку після паузи.

- stop_print() -> bool
  Опис: Надсилає команду MQTT "stop" для повного скасування та зупинки друку.

- set_speed_level(level: int) -> bool
  Опис: Перемикає швидкість принтера (1: Silent 50%, 2: Standard 100%, 3: Sport 124%, 4: Ludicrous 166%).

- toggle_chamber_light(mode: str = "toggle") -> bool
  Опис: Керує підсвіткою камери друкарського відсіку (вмикає, вимикає або перемикає).

- calculate_job_cost(weight_grams: float, print_mins: int = 0) -> Dict[str, float]
  Опис: Обчислює собівартість друку в грн: сума вартості витраченого пластику та 
        спожитої електроенергії.

- to_dict() -> Dict[str, Any]
  Опис: Серіалізує поточні налаштування та стан принтера у словник для запису у JSON.


7. ФАЙЛ: storage/manager.py (Клас StorageManager)
--------------------------------------------------------------------------------
- __init__(base_dir: Path)
  Опис: Ініціалізує менеджер зберігання даних та створює необхідні папки.

- _get_lock(path: Path) -> asyncio.Lock
  Опис: Повертає або створює унікальний асинхронний м'ютекс (Lock) для конкретного файла.

- load_json(path: Path, default: Any) -> Any
  Опис: Асинхронно зчитує JSON-файл з використанням aiofiles та пер-файл блокування.

- save_json(path: Path, data: Any) -> bool
  Опис: Асинхронно записує структуру даних у JSON-файл з форматуванням indent=2.

- load_user(user_id: str) -> Dict[str, Any]
  Опис: Завантажує або створює профіль користувача з налаштуваннями сповіщень та прав.

- save_user(user_data: Dict[str, Any])
  Опис: Зберігає дані профілю користувача у відповідний JSON-файл.

- load_all_users() -> Dict[str, Dict[str, Any]]
  Опис: Завантажує профілі всіх зареєстрованих користувачів бота.

- load_spools() -> Dict[str, Dict[str, Any]]
  Опис: Завантажує каталог доступних котушок філаменту з spools.json.

- save_spools(spools: Dict[str, Dict[str, Any]]) -> bool
  Опис: Зберігає оновлений каталог котушок у spools.json.

- load_history() -> List[Dict[str, Any]]
  Опис: Завантажує історію виконаних завдань друку.

- add_history_entry(entry: Dict[str, Any]) -> bool
  Опис: Додає новий запис до історії друку (з обмеженням у 500 останніх деталей).

9. ФАЙЛ: services/camera_stream.py
--------------------------------------------------------------------------------
- check_tcp_port_open(ip: str, port: int, timeout: float = 1.0) -> bool
  Опис: Перевіряє відкритість мережевого порту по TCP.

- _fetch_bambu_port6000_jpeg(ip: str, access_code: str) -> Optional[bytes]
  Опис: Підключається до бінарного TLS-потоку Bambu Lab (порт 6000), надсилає 
        64-байтний пакет авторизації та зчитує живий JPEG кадр.

- capture_real_camera_photo(ip: str, access_code: str) -> Optional[bytes]
  Опис: Асинхронна функція отримання фото з камери з повторними спробами та HTTP-фолбеком.


10. ФАЙЛ: services/ftps_client.py
--------------------------------------------------------------------------------
- ImplicitFTP_TLS.connect(host, port, timeout)
  Опис: Перевизначений метод підключення FTPS для підтримки неявного TLS (Implicit) на порту 990.

- extract_model_weight(print_data: Dict[str, Any]) -> float
  Опис: Шукає вагу моделі у відповідях MQTT або за допомогою регулярних виразів у назвах.

- parse_weight_from_gcode_text(text: str) -> float
  Опис: Витягує вагу в грамах з коментарів G-коду (filament used [g] = ...).

- parse_weight_from_3mf_bytes(data_bytes: bytes) -> float
  Опис: Розпаковує .3mf zip-контейнер та зчитує вагу з slice_info.config або .gcode.

- _connect_bambu_ftps(ip: str, access_code: str)
  Опис: Підключається до FTPS-сервера принтера (порт 990 Implicit або 21 Explicit).

- fetch_bambu_ftps_weight(ip: str, access_code: str, target_filename: str = "") -> float
  Опис: Завантажує останній слайсений файл з SD-карти принтера по FTPS і витягує його точну вагу.


11. ФАЙЛ: services/gcode_parser.py
--------------------------------------------------------------------------------
- parse_time_str(time_str: str) -> int
  Опис: Перетворює рядок часу (наприклад, "1h 20m", "01:20:00") у хвилини.

- resolve_model_name(raw_model: str) -> str
  Опис: Нормалізує назву моделі принтера (A1 mini, A1, P1P, P1S, X1C) з пресетів та суфіксів.

- parse_3mf_file(file_bytes: bytes, filename: str = "") -> Dict[str, Any]
  Опис: Проводить повний аналіз .3mf чи .gcode файла (XML, JSON, G-code) та 
        повертає модель принтера, тип пластику, вагу і час друку.

- check_compatibility(sliced_model: str, filament_type: str, target_printer_name: str) -> Dict[str, Any]
  Опис: Перевіряє фізичну сумісність нарізаного файлу з обраним принтером ферми.


12. ФАЙЛ: services/gif_generator.py
--------------------------------------------------------------------------------
- generate_printer_status_gif(printer: Any) -> bytes
  Опис: Генерує анімовану GIF-картку з графічною візуалізацією руху сопла, 
        температурами та прогресом друку.


13. ФАЙЛ: utils/math_eval.py
--------------------------------------------------------------------------------
- safe_eval_math(expr_str: str) -> Optional[float]
  Опис: Безпечно обчислює арифметичні вирази (наприклад, "1000 - 250") за допомогою 
        AST без ризиків використання eval().


14. ФАЙЛ: app.py (Клас PrinterBotApp)
--------------------------------------------------------------------------------
- __init__()
  Опис: Конструктор головного додатку бота.

- initialize()
  Опис: Завантажує конфігурації принтерів та ініціалізує MQTT-клієнти.

- save_printers_config()
  Опис: Зберігає поточні конфігурації принтерів у printers.json.

- is_user_admin(user_id: str) -> bool
  Опис: Перевіряє, чи має користувач адмін-права.

- is_user_approved(user_id: str) -> bool
  Опис: Перевіряє, чи підтверджено доступ користувача до бота.

- send_notification(event_type: str, text: str, reply_markup: Optional[Any] = None)
  Опис: Надсилає сповіщення усім авторизованим користувачам з ураженням їхніх налаштувань.

- get_notify_keyboard(u_notify: dict) -> ReplyKeyboardMarkup
  Опис: Будує клавіатуру для індивідуального налаштування сповіщень користувача.

- cmd_start(message: Message)
  Опис: Обробник бота для команди /start.

- handle_message(message: Message)
  Опис: Головна текстова маршрутизація повідомлень, кнопок меню, адмінки та FSM.

- handle_callback_query(callback: types.CallbackQuery)
  Опис: Обробник натискань на інлайн-кнопки (наприклад, для підтвердження списання пластику).

- handle_document(message: Message)
  Опис: Приймає та обробляє завантажені файли .3mf/.gcode для відправки на друк.

- monitoring_loop()
  Опис: Фоновий асинхронний цикл моніторингу станів принтерів (над надсиланням сповіщень).

- run()
  Опис: Запускає aiogram bot polling та фоновий процес моніторингу.
