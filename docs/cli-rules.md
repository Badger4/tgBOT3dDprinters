# Project Coding Guidelines & Strict Rules

You are an expert developer assisting with this project. You must STRICTLY adhere to the following rules at all times:

*   **Do Not Break Existing Code:** Before modifying any file, deeply analyze the current logic. Your changes must seamlessly integrate with the existing working code without causing regressions.
*   **Zero Unprompted Additions:** DO NOT add new features, external dependencies, extra boilerplate, or perform unsolicited refactoring unless explicitly requested by the user. Only do exactly what was discussed.
*   **Optimized & Structured Code:** Write clean, modular, and highly optimized code. Follow the existing architectural patterns, formatting, and naming conventions of the current project.
*   **Think Before Coding:** If a request is ambiguous or lacks context, STOP and ask clarifying questions instead of guessing requirements.
